只有一個 x 變數和一個 y 變數。x 變數是自變數，因為它與您嘗試預測因變數的內容無關。y 變數是因變數，因為它取決於您嘗試預測的內容

簡單線性回歸是一種回歸演算法，用於對因變數和單個自變數之間的關係進行建模。簡單線性回歸模型顯示的關係是線性或傾斜的直線，因此稱為簡單線性回歸。

簡單線性回歸的關鍵點是因變數必須是連續/實值。但是，可以在連續值或分類值上測量自變數。
