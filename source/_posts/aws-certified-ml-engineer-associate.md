# 考試資訊

- 考試時間: 130 分鐘
- 考試形式: 65 個問題
- 費用: 150 USD
- 測驗選項: Pearson VUE 測驗中心或有監考人員的線上考試
- 提供的語言: 英文、日文、韓文和簡體中文

前往 AWS 官方查看 [AWS Certified Machine Learning Engineer – Associate 考試資訊](https://aws.amazon.com/tw/certification/certified-machine-learning-engineer-associate/)。

## 考試成績
100–1000 分，最低通過分數為 720 分。

## 問題類型
- 單選題: 1 個正確答案及 3 個錯誤答案。
- 多選題: 從 5 個或更多選項中包含 2 個或以上正確答案。需選擇所有正確答案。
- 排序題：提供 3–5 個選項，需按照指定任務選擇正確答案並以正確順序排列。
- 配對題：提供一組選項與 3–7 個提示，需將選項與提示正確配對。
- 案例題：基於單一案例提出 2 個或更多問題。

## 考試範圍
- ML 資料處理 (28%)
- ML 模型開發 (26%)
- ML 工作流程的部署與配置 (22%)
- ML 的監控、維護與安全性 (24%)

前往 AWS 官方查看 [AWS Certified Machine Learning Engineer – Associate 考試指南](https://d1.awsstatic.com/training-and-certification/docs-machine-learning-engineer-associate/AWS-Certified-Machine-Learning-Engineer-Associate_Exam-Guide.pdf)。

# 總結
這次通過 AWS Certified Machine Learning Engineer – Associate(MLA-C01) 的認證，分數比之前考取的 AWS Certified AI Practitioner(AIF-C01) 還要高，因為兩張證照之間有許多重疊的核心觀念。AI Practitioner 是基礎，專注於人工智慧的基本概念與 AWS 相關服務的入門知識，而 ML Associate 則進一步深入到了機器學習的具體應用，包括數據準備、模型開發、部署與監控。

我想考試不僅是對技術知識的驗證，更是一種激勵自我延伸學習的方法，希望這篇經驗分享能夠幫助更多想要挑戰 MLA-C01 認證的朋友們，讓我們一起踏上學習與成長的旅程吧！
