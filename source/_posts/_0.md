# 預訓練 (Pre-training) 

 🍷 FineWeb, a new, large-scale (15-trillion tokens, 44TB disk space) dataset for LLM pretraining

https://huggingface.co/spaces/HuggingFaceFW/blogpost-fineweb-v1

資料收集與清洗：從 Common Crawl 等來源下載海量網頁，並進行嚴格的過濾（移除惡意軟體網站、成人內容、語言篩選與個資移除），最終獲得如 FineWeb 般約數十 TB 的高質量純文本資料集
。
分詞技術 (Tokenization)：神經網路無法直接理解文字，必須透過「位元組對編碼 (BPE)」演算法，將文本切分成有限的符號（即 Token）
。例如 GPT-4 使用了大約 10 萬個不同的 Token 符號來表示所有文字
。
預測下一個 Token：預訓練的核心是在擁有數十億參數的 Transformer 神經網路上，輸入一段 Token 序列（上下文），並訓練模型預測序列中的下一個 Token
。這需要耗費數千張 GPU 進行數個月的龐大算力
。
基礎模型 (Base Model) 的產出：此階段產出的模型只是一個「高級的字詞自動完成工具」或網路文件的隨機模擬器，它並不是能回答問題的助理
。這些模型可以視為網際網路的「有損壓縮」，將海量知識以機率的形式儲存在其參數中
。

# 強化學習 (RL)

學習的三階段比喻：預訓練就像是閱讀教科書的背景知識；監督式微調就像是模仿教科書上的範例解答；而強化學習則是讓模型自己做「練習題」，透過試錯來發現最佳解法
。
自動發現思考策略：在可驗證的領域（如數學、寫程式）中，模型會產生多種解答路徑，並透過檢驗最終答案是否正確來強化正確的路徑
。這使得模型（如 DeepSeek R1 或是 OpenAI 的 O 系列）學會了「思維鏈 (Chain of Thought)」，懂得重試、檢查錯誤，大幅提升了推理能力
。
人類回饋強化學習 (RLHF) 的局限：對於無法自動驗證對錯的任務（如寫詩或講笑話），開發者會訓練一個「獎勵模型 (Reward Model)」來模擬人類評分，然後讓 LLM 對著這個獎勵模型進行強化學習
。然而，這種方法容易被模型「鑽漏洞 (gaming)」，產生分數極高但毫無意義的廢話，因此它更像是一種微調，缺乏真正無窮盡強化學習的魔法潛力
