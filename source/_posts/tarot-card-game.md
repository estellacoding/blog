# 玩法
塔羅通關是一款讓我們與指導靈同在尋找答案的桌遊，萬事萬物都可以用塔羅通關去詢問，並且透過遊玩的方式，找到問題的狀態，指導靈會協助你方向，找到屬於自己的靈魂碎片。

## 設定問題
遊戲開始前，要先設定這次遊戲想要詢問的問題。
> 我這次的問題是:
> 如何與自己連結？
> 我的人生使命是什麼？

## 執行任務
遊戲中開始後，玩家輪流丟骰子，走到哪個位置就執行不同任務，並寫下感受。
- 火: 抽取火牌
- 水: 抽取水牌
- 風: 抽取風牌
- 土: 抽取土牌
- 大牌: 抽取大牌
- 指引: 抽取指引牌
- 人格: 抽取人格牌
- 內觀: 抽取內觀牌
- 寬恕: 丟棄手中的一張牌卡，並說明原因
- 請求: 可任意拿取桌上玩家的牌卡
- 協助: 主動將手中的一張牌卡送其中一個玩家
- 前世: 可隨機抽取遊戲場上的任何牌卡
- 許願: 寫下你的願望，100%都會實現

{% note info %}
如果有走到許願的位置，表示指導靈要給你禮物了♥️~~要記得勇敢跟指導靈開口要你的願望，只要你願意擁有，敢說出來，指導靈就一定敢給你。
{% endnote %}

## 三個階段
過程分成三個階段，分別是過去、現在、未來。

## 通關條件
進入下一階段的通關條件:
- 每個階段都必須搜集到2張塔羅牌、1張內觀牌、1張人格牌，及1張指引牌。
- 或是，剛好走到遊戲中的起始點位置上。

{% note info %}
每一張牌的出現，都是指導靈在對你說話喔。
{% endnote %}

# 過去
我第一張抽到人格牌「富翁」，在遊戲中寬恕了這張牌。

我手上的牌卡是:
- 指引牌: 「溝通」
- 人格牌: 「投機」
- 大牌: 「太陽」，這張是被協助而獲得的牌
- 其他: 「寶劍6」、「聖杯6」

最後走到遊戲中起始點上，就進入下一階段。

<div class="callout">
  <span class="callout-icon">💡</span>
自我解讀:<br>
<strong>重新看見「自己的光」與「可以快樂、自然地做自己」的可能性。</strong><br>
我曾努力追求外在的擁有，如富翁與投機來證明自己，但經歷過幾次心靈上的轉折與他人的幫助下，後來才慢慢意識到，其實真正的價值來自於與人的連結、知識的累積、以及找回那個單純喜悅的自己，並打從心裡相信「我值得被愛、值得快樂」這件事。
</div>

{% note info %}
提供一個小技巧，將「塔羅通關遊戲規則」及「你抽到的牌卡」(圖片+文字)，請chatGPT協助你解讀每個階段的塔羅牌卡意義，可以參考我的 [提示詞](https://chatgpt.com/share/67fc9732-6864-800b-9763-1188f2d19da1)。
{% endnote %}

# 現在

我手上的牌卡是:
- 指引牌: 「熱情」、「使命」、「單純」
- 內觀牌: 「原諒」、「放下」
- 大牌: 「月亮」、「調節」
- 其他:  「圓盤公主」、「圓盤4」、「圓盤5」、「聖杯5」、「寶劍7」、「寶劍8」、「權杖8」
- 許願一次: **<u>所做的選擇都在熱情上，燃燒內在小宇宙像太陽照亮別人</u>**。

中間我手上已經有太多牌時，鴨鴨此時就告訴我，，有沒有發現到: 遲遲抽不到人格牌？因為我被動了接受外界的角色，認為要手握這麼技能才能被認可，但 **<u>「不是你擁有什麼，而成為什麼樣的人，而是你先是那樣的人，就會擁有什麼」</u>**，

最後被協助人格牌「霸凌者」，就進入下一階段。

<div class="callout">
  <span class="callout-icon">💡</span>
自我解讀:<br>
<strong>當回到熱情與單純，使命就會自然顯現。</strong><br>
我現在正處於「靈魂重組」的關卡，而靈魂正在帶我穿越黑暗森林，讓我覺醒，我需要拆解舊有的身份、限制、價值觀，面對不安全感與恐懼，放下控制與批判，這段時間也許有壓力、有誤解、有努力無效的感覺，最終破繭重建出一個熱情、使命、單純的我。
</div>

# 未來
我在未來的第一步走到<u>**協助的位置**</u>，因我手上沒有任何一張牌，所以我可以隨機抽取任何種類牌卡給其中一位玩家。我當下就遲疑不知道要選什麼給哪位玩家，這時候鴨鴨叫我閉上眼睛，想:「要抽什麼牌給誰」，並說當我睜開眼睛時，我就能立刻知道要抽什麼牌卡，並給其中一位玩家。

而第二步<u>**竟然就直接走到遊戲中起始點上**</u>，在沒有任何牌卡的情況下，就直接結束這個階段了(~~我當下也傻眼，我的指導靈覺得我能憑空取物嗎😶~~)。鴨鴨叫我想一下指導靈想要告訴我什麼？

<div class="callout">
  <span class="callout-icon">💡</span>
自我解讀:<br>
<strong>回到起點＝圓滿。</strong><br>
指導靈想告訴我，不需要再努力奔跑、不需要再證明什麼，這不代表失去一切，而是「重啟」。我會以全新的姿態、真正自由的意志，重新開始，但這次是出於愛與使命，而不是責任或壓力。當我成為空的容器，我便能夠盛裝萬物，並開始給予他人我最真誠的禮物。<br>
</div>

# 結語

這次的塔羅通關，帶我走一次深度的自我探索的旅程。這不僅是一款桌遊，其實更像是一場生命劇本的覺察，帶我穿梭過去、現在與未來，重新定義內在的光與力量。在主持人鴨鴨超專業引導下，讓每位玩家都能更進一步去思考自己最真實的模樣，從中體驗到指導靈的訊息與禮物。推推！

> 不是努力證明自己，而是勇敢成為自己。
> 祝福所有踏上探索旅程的勇者，都能在未知生命中找到屬於自己的答案。
